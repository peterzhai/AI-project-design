# 第 7 章 · 练习

## 练习 1（热身）：句子感知切块

实现 `chunk_by_sentence(text, doc_id, max_size=60)`：按中文句号/问号/感叹号切句，
相邻句子合并直到不超过 max_size（单句超限时整句单独成块）。

**验收标准**：
- 块内不含被切断的句子（每个块以句号结尾，或为唯一超限句）；
- 原文所有句子都在某个块中出现（不丢字）；
- pytest 覆盖正常与超限两种情况。

**参考答案要点**：
- `re.split(r"(?<=[。？！])", text)` 保留分隔符的切法；
- 合并时用贪心（装得下就装），这是检索质量与块数量的常见折中。

## 练习 2（进阶）：TF-IDF 加权的嵌入

当前伪嵌入对"的、了、是"这类停用词与实词一视同仁。请改进 `embed`：
对每个 bigram 计算 `count * log(N / df)` 加权（N=文档块总数，df=包含该 bigram 的块数），
即在**索引建立时**统计文档频率，检索时查询向量用同一权重表。

**验收标准**：
- 含高频停用词与含实词的两段文本，加权后实词段得分上升；
- 与原始均匀权重相比，示例 02 中"年假"问题的第一命中率不变（回归）；
- pytest 覆盖权重生效（对比两种嵌入的得分差）。

**参考答案要点**：
- `VectorIndex` 需要 `_df: Counter` 在 add 时统计；权重表是索引的状态 ——
  这解释了为什么生产嵌入模型要"先有语料再有向量"。
- 这练习直通第 8 章：打分与权重思想在"任务优先级排序"里同样适用。

## 练习 3（挑战）：RAG + 引用校验的"重试闭环"

把第 3 章的修复闭环思想用到 RAG：答案存在非法引用（幻觉）时，不直接返回，
而是把「答案 + 非法引用列表」喂回模型让它修正，最多 2 次；仍失败则标记 `degraded=True` 返回。

**验收标准**：
- Mock 脚本：第 1 次引用 policy#99、第 2 次引用合法 -> 最终 `invalid_citations == []`；
- 两次都非法 -> `degraded=True` 且答案保留（供人工复核）；
- pytest 断言调用次数与两种结局。

**参考答案要点**：
- 喂回时要带上"合法块 id 清单"，模型才知道往哪改 —— 与第 3 章"带错误信息回炉"同理。
- `degraded` 标记是"诚实地交付不完美的结果"：宁可标记可疑，也不静默放过幻觉 ——
  第 10 章评估、第 11 章护栏会大量使用这种"降级不隐瞒"模式。
